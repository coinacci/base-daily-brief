## 📢 NEWS

### Vibenet: 200ms blocks, Validity Tx, native AA
**Source:** @dmericliu · @jessepollak — Sep 2

Base engineer Eric Liu opened Vibenet. Three features are live to try.

**200ms blocks.** Confirmation is native — no separate Flashblocks layer, and existing contracts do not need to change. Apps are meant to feel instant.

**Validity Transactions.** A transaction carries a condition — a price, a block, a flashblock index — and waits until that condition is true. Instead of guessing and retrying, the order sits. Searchers and market makers waste fewer probe transactions and get safer fills.

**EIP-8130 native account abstraction.** Gas sponsorship, session keys, and batched calls sit in the protocol. Smart-account UX no longer needs a separate smart-contract wallet, a bundler, or an alternate mempool.

Jesse wrote "new features on Base shipping on vibenet." Youssef was explicit that Vibenet is ephemeral — state is not guaranteed and the network can go down. Chain ID `84538453`, RPC `https://rpc.vibes.base.org`. The Cobalt upgrade is the path to mainnet; Sepolia and mainnet dates remain TBD.

Last week's stocks and wraps added assets onto the chain. This changes the chain itself. Native 200ms blocks matter for 24/7 tokenized-stock trading and LP — the book and the oracle start to feel sub-second. Validity Transactions cut the DeFi habit of "send, revert, retry." EIP-8130 means the agent research → pay → execute path gets wallet UX as a protocol feature instead of an app feature. Vibenet is ephemeral — no real TVL, no real user money, no mainnet date. Today's information is not "Base got faster." It is "Base opened 200ms blocks and native AA for public rehearsal before Cobalt."

### Creator Grant Program
**Source:** @base — Sep 2

Base opened a Creator Grant Program for independent creators — up to **$4,000** for work about Base, the ecosystem, and builders. The ask is writers, streamers and recurring-show hosts, independent video creators, and educators covering Base in their own language. There is also a weekly "creator of the week" bounty of **up to $500** for emerging creators. The application form is in the official thread.

This is not a protocol or asset story — it is distribution. The last two weeks widened the product surface; Base is now paying independent voices to explain it. The "in their own language" line matters: translating the stock story into local languages is written as a need, not an afterthought. A grant does not buy Base's editorial line, but it marks what gets funded. The practical read for an applicant is recurring, Base-locked work — not generic crypto content.
