### CDP Borrow — credit inside the app, Morpho Blue, Base
**Source:** @CoinbaseDev — Sep 22

Coinbase Developer Platform added Borrow to Wallets. Crypto-backed USDC loans inside an application. First protocol Morpho Blue, Base mainnet, CDP Smart account. Supported pairs: cbBTC/USDC, cbXRP/USDC, SOL/USDC, cbETH/USDC.

The whole flow is a user operation. A paymaster can sponsor gas; CDP transaction policy applies to the same borrow. The developer sets an origination fee and a recipient in the Portal. The API carries the position lifecycle: browse pairs, post collateral and borrow atomically, add or withdraw collateral, repay, close, track debt/APY/health.
